# 0001 · Dirección visual: carta coleccionable

- **Estado**: aceptada
- **Fecha**: 2026-11-19

## Contexto

La maqueta v0 («hierba alta nocturna») era sólida en lógica pero se sentía como un panel de desarrollador: fondo casi negro, verdes de contribución y tipografía técnica. El objetivo es que se sienta Pokémon, no informática.

## Opciones exploradas

Las tres están en [`docs/bocetos/v1/1-direcciones-a-b-c.html`](../bocetos/v1/1-direcciones-a-b-c.html), todas con PokeAPI real:

| | Dirección | Idea |
|---|---|---|
| A | Pokédex | El aparato rojo abierto: arte en la pantalla, descripción en LCD verde, repos como teclas. |
| B | Combate | Encuentro salvaje: transición, avatar pixelado como entrenador, menú LUCHAR/HUIR. |
| C | Carta holo | Carta coleccionable con brillo holográfico que sigue al cursor. |

También se probó un híbrido A+B+C ([`2-hibrido.html`](../bocetos/v1/2-hibrido.html)).

## Decisión

Dirección **C, carta coleccionable**, ampliada a un **sobre de 6 cartas**: el compañero (todo el perfil) y un Pokémon por cada uno de los 5 repos más activos. Recupera la idea de «equipo de 6» del concepto v0 en un formato que se colecciona y se comparte.

## Consecuencias

- La rareza (común → variocolor) se vuelve el gancho del revelado.
- El intercambio entre amigos sale natural del formato carta.
- La tarjeta para el README (v0.3) se diseña como una carta, no como un panel.
